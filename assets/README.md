# assets/ — сюда кладём материалы от заказчика

Всё необязательно. Что положено — имеет приоритет над скачанным автоматически.

| Папка / файл | Что положить | Имена |
|---|---|---|
| `photos/` | Фото Мира в высоком качестве (JPG/PNG/HEIC→JPG) | любые; `avatar.jpg` — аватар; `about.jpg` — главный портрет |
| `screens/` | Скриншоты профилей с телефона | `instagram.png`, `tiktok-rinkiwi.png`, `tiktok-miirakhh.png` |
| `stats/` | Скриншоты статистики аудитории Instagram / TikTok | любые |
| `logos/` | Логотипы брендов (лучше SVG, иначе PNG на прозрачном фоне) | `<slug>.svg` — slug из `content/mediakit.json` (например `fata.svg`, `axisy.svg`) |
| `art/` | Рисунки Мира | любые |
| `prices.txt` | Прайс свободным текстом + валюта | — |

Файлы cookies/логины сюда **не класть** — только в `secrets/` (она в `.gitignore`).
