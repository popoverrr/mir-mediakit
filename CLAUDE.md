# CLAUDE.md — инструкция для Claude Code

Ты делаешь сайт-медиакит блогера **MIR** (Мирахмад Миркобилжонов). Полное ТЗ — `TZ.md`. Данные — `content/mediakit.json`. Референс дизайна — `reference/ref-01…11.jpg`.

Работай автономно от начала до конца. Вопросы заказчику не задавай — всё, чего не хватает, закрывай fallback-ами из ТЗ и выписывай в `REPORT.md`.

## Порядок работы

1. **Прочитай** `TZ.md` целиком, `content/mediakit.json`, `CHECKLIST.md`, `assets/README.md`.
2. **Посмотри референс**: открой все `reference/ref-*.jpg` (инструментом Read) и зафиксируй для себя типографику, градиенты, стекло, композицию.
3. **Проверь, что заказчик положил в `assets/`** (фото, скриншоты профилей, логотипы, статистику, рисунки). Если в `assets/stats/` есть скриншоты статистики — перенеси цифры в `content/mediakit.json → audience` (только то, что видно на скриншоте). Если в `assets/prices.*` есть прайс — заполни `formats[].price`, `ambassadorship`, `pricing.currency`.
4. **Медиа.** Окружение пользователя — Windows (PowerShell). Установи и запусти:
   ```powershell
   python -m pip install -U -r scripts/requirements.txt
   winget install --id Gyan.FFmpeg -e      # если ffmpeg ещё нет; после установки открыть новый терминал
   python scripts/fetch_media.py --dry-run
   python scripts/fetch_media.py
   ```
   - Если Instagram-ролики не скачались, а в системе есть Firefox с входом в Instagram — повтори для них: `python scripts/fetch_media.py --only kima-beauty,gsjj,intro --cookies-from-browser firefox`. Из Chrome на Windows yt-dlp обычно не может достать cookies (App-Bound шифрование) — если Firefox нет, не трать время, оставь embed.
   - Если есть файл `secrets/cookies.txt` — используй `--cookies secrets/cookies.txt` (и `--gallery` для фото-постов, если установлен gallery-dl).
   - Скрипт идемпотентный: повторный запуск докачивает только недостающее.
   - Что не скачалось — не блокер: на сайте работает fallback (§6.4–6.5 ТЗ).
5. **Отбери фото** (§6.2 ТЗ): просмотри `assets/photos/`, `media-src/gallery/`, `media-src/stills/`, выбери лучшие, скадрируй, положи в `src/assets/photos/`. Для блока «Обо мне» попробуй вырезать фон (`rembg`) — если край грязный, используй обычное фото.
6. **Собери проект** на Astro по §2 ТЗ. Сначала каркас + данные + все секции без анимаций, потом дизайн, потом моушн.
7. **Проверь в браузере** (Playwright или встроенный браузер): 375×812 и 1440×900, RU и EN, фильтры, модалка, видео. Сохрани скриншоты в `docs/screens/`. Исправь всё, что выглядит сломанным или «дёшево».
8. **Lighthouse** мобайл — прогони, добейся порогов из §9.
9. **Напиши `REPORT.md`**: как запустить, что скачалось/нет (из `content/media-manifest.json`), откуда фото, какие fallback-и сейчас активны, что осталось получить от заказчика (сверить с `CHECKLIST.md`), как задеплоить на Vercel.
10. Если это git-репозиторий — закоммить итог. Если нет — `git init` и один коммит.

## Жёсткие правила

- Все цифры и факты — только из `content/mediakit.json` (и из `assets/`, которые положил заказчик). `null` → fallback, а не выдумка.
- Ничего из референса (фото, логотипы, имя Адиля, его телефон) на сайт не попадает.
- Никаких iframe соцсетей до клика пользователя.
- `media-src/`, `secrets/`, `node_modules/`, `dist/` — в `.gitignore`.
- Весь интерфейс — на русском, плюс английская версия `/en/`.
- Сайт должен выглядеть как дорогой медиакит, а не как шаблон лендинга: крупная типографика, воздух, ровная сетка, аккуратные стеклянные карточки, никакого «AI-slop» (эмодзи вместо иконок, фиолетовые градиенты по умолчанию, одинаковые карточки с тенью).
