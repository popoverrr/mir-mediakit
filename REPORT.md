# REPORT — медиакит MIR

Сборка от 25.09.2026. Всё сделано по `TZ.md` и `CLAUDE.md`; вопросы заказчику не задавались, недостающее закрыто fallback-ами из ТЗ (список ниже).

## 1. Как запустить

```bash
npm install
npm run dev       # разработка, http://localhost:4321
npm run build     # постеры → OG → astro check → dist/
npm run preview   # собранный сайт
```

Node 22.12+. Медиа уже лежат в `public/media/`; перекачать или докачать — `python scripts/fetch_media.py` (подробности в `README.md`).

## 7. Решения и отступления

- **Флаги** 🇰🇿 🇺🇿 нарисованы SVG: эмодзи-флаги в Windows показываются буквами, а правило «никаких эмодзи вместо иконок» из CLAUDE.md.
- **Шрифты**: у Oswald, Unbounded и Manrope в `@fontsource` есть кириллица — замен нет. Подключены только латиница и кириллица нужных начертаний (Oswald 700, Unbounded 500/700, Manrope 400/600), Oswald предзагружается.
- **Featured на десктопе**: их 9, поэтому не сетка (осталась бы одна карточка в третьем ряду), а лента «4 в ряд» со стрелками.
- **Звук в модалке**: ролик запускается со звуком, потому что модалку открывает клик пользователя (как YouTube-embed с `autoplay=1` из ТЗ). Превью в карточках — всегда без звука.
- **Метрики в модалке** — у ролика, который сейчас играет; итоги кампании — строкой над ними.
- **Доказательство в «Долгосрочно»**: цифры берутся из `cases[].totals.videos` брендов, названных в `ambassadorship.proof`, — текст и цифры не разойдутся.
- **Порядок «Кейсов»** по ТЗ: featured → `knownViews` по убыванию → без просмотров в конце.
- **Арт-слой** — рисунки Мира в режиме soft-light с растворёнными краями, только в «Обо мне» и «Контактах».
- Из референса на сайте нет ничего (ни фото, ни логотипов, ни имени, ни контактов). Папка `reference/` в `.gitignore` — в ней чужой медиакит с личными данными.

## 9. Деплой на Vercel

1. vercel.com → Add New → Project → импортировать репозиторий.
2. Framework Preset: **Astro** (Build: `npm run build`, Output: `dist`, Node 22).
3. Deploy. Для своего домена: Settings → Domains, плюс переменная `MIR_SITE=https://<домен>` — от неё строятся canonical, hreflang и адреса OG-картинок, затем Redeploy.

Превью на GitHub Pages собирает `.github/workflows/pages.yml` (base = `/<репозиторий>/`).
