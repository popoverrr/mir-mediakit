# ТЗ: сайт-медиакит блогера MIR (Мирахмад Миркобилжонов)

Версия 1.0 · 25.09.2026 · язык сайта: RU (основной) + EN

---

## 0. Суть задачи

Сделать **одностраничный сайт-медиакит** для блогера **Mir / Мирахмад Миркобилжонов** (@miirakhmad). Сайт отправляют рекламодателям вместо PDF, поэтому он должен за 30 секунд объяснить бренду: кто это, какой у него охват, с кем он уже работал и как с ним связаться.

За основу берём **структуру и визуальный язык PDF-референса** (`reference/ref-01…11.jpg`, медиакит другого блогера — Адиля Тасболатова) и делаем из него **живой сайт с фото и видео**: ролики кейсов проигрываются прямо на странице, цифры анимируются, есть фильтр кейсов.

> ⚠️ Из референса берём только структуру и стиль. **Никаких данных, имён, фото, логотипов и контактов Адиля на сайте быть не должно.**

## 2. Стек и структура проекта

- **Astro** (актуальная стабильная версия, `output: 'static'`), TypeScript, без UI-фреймворков. Интерактив — маленькие `<script>` на ванильном TS.
- Стили — обычный CSS с дизайн-токенами на `:root` (без Tailwind, без CSS-in-JS).
- Шрифты — через `@fontsource/*` (self-host, **обязательно с кириллицей**).
- Картинки из `src/assets/` — через `astro:assets` (`<Image>`/`<Picture>`, AVIF/WebP). Видео — из `public/media/` (их готовит скрипт).
- Анимации — CSS + IntersectionObserver. Можно `motion` (motion.dev), если реально нужно. **Нельзя**: GSAP-плагины, three.js, jQuery, слайдер-библиотеки весом > 15 КБ.
- Node 20+. Команды: `npm run dev`, `npm run build` → `dist/`, `npm run preview`.

Рекомендуемая структура:

```
/                     ← корень архива = корень проекта
├─ content/mediakit.json          ← данные (не дублировать в код!)
├─ content/media-manifest.json    ← генерирует scripts/fetch_media.py
├─ public/media/{cases,thumbs}/   ← генерирует скрипт
├─ media-src/                     ← сырьё скрипта (в .gitignore)
├─ src/
│  ├─ assets/photos/              ← отобранные фото Мира (из assets/photos или стоп-кадров)
│  ├─ assets/logos/               ← логотипы брендов (если есть)
│  ├─ components/                 ← Hero.astro, Stats.astro, About.astro, Platforms.astro,
│  │                                 Partners.astro, Cases.astro, CaseCard.astro, VideoModal.astro,
│  │                                 TopContent.astro, Audience.astro, Formats.astro,
│  │                                 Longterm.astro, Contacts.astro, Nav.astro, PhoneMock.astro
│  ├─ lib/data.ts                 ← загрузка JSON + manifest, типы, хелперы (fmtNumber, pickPoster, pickPlayer)
│  ├─ i18n/{ru,en}.ts             ← только UI-строки (заголовки, кнопки); контент — из JSON
│  ├─ styles/{tokens,global}.css
│  └─ pages/index.astro, pages/en/index.astro
└─ scripts/fetch_media.py
```

## 3. Данные: правила

1. **Всё берётся из `content/mediakit.json`.** Никаких чисел и фактов, захардкоженных в компонентах.
2. **Ничего не выдумывать.** `null` = данных нет → работает fallback из этого ТЗ (скрыть блок, «по запросу», заглушка). Нельзя ставить «примерные» проценты аудитории, цены, отзывы.
3. Цифры собраны 25.09.2026 (`meta.collectedAt`) — в футере: «Данные обновлены: 25 сентября 2026».
4. Форматирование чисел — через `Intl.NumberFormat(locale, { notation: 'compact' })`: RU → «2,5 млн», «727 тыс.»; EN → «2.5M», «727K». Для крупных счётчиков — «2 млн+», «25 млн+» (округление вниз + «+»).
5. Двуязычные поля — объекты `{ ru, en }`. UI-строки — в `src/i18n`.
6. Типизировать JSON в `src/lib/data.ts` (interfaces). Если поле отсутствует — не падать, а применить fallback.
7. `extraIntegrations` (найдены на YouTube, но не были в списке заказчика) **не показывать**, пока у элемента `include: false`.
8. Кейс с `showInCases: false` (Sodamoda — нет ролика) показывать **только** в блоке «Партнёры».

Ключевые цифры (уже посчитаны в `totals`):
- **2 093 100** подписчиков на всех площадках → «2 млн+»
- Instagram **770 тыс.** · TikTok @rinkiwi **1,2 млн** (47,9 млн лайков) · TikTok @miirakhh **82 тыс.** (5,9 млн лайков) · YouTube **41,1 тыс.**
- YouTube Shorts: **68 млн+** просмотров на 322 шортсах, 13 роликов > 1 млн
- Реклама: **24 бренда**, **62 ролика**, **25,5 млн+** известных просмотров (Instagram-просмотры не учтены — их не видно без входа)
- Рекорд интеграции: **Fata — 2,5 млн просмотров, 51 тыс. репостов**; **AXIS-Y — 2,6 млн** на YouTube Shorts

## 4. Дизайн

### 4.1 Что берём из референса
Смотри `reference/ref-01…11.jpg`. Сохраняем:
- **Огромные сжатые заголовки капсом** (как «АДИЛЬ ТАСБОЛАТОВ», «ПАРТНЕРЫ», «СТАТИСТИКА») — занимают треть экрана.
- **Широкий гротеск капсом** для подзаголовков/лейблов («MEDIA KIT», «СТОРИС В INSTAGRAM»).
- **Градиент «сталь → тёмный»**: светлый серебристый верх секции плавно уходит в почти чёрный низ.
- **Стеклянные карточки** (glassmorphism) с тонкой светлой обводкой и большим радиусом.
- **3D-телефоны с профилями** на первом экране + **хромированная «лента»**, проходящая через кадр.
- **Сцена с экраном логотипов** в блоке «Партнёры».
- **Карточки статистики как в интерфейсе Instagram/TikTok** поверх фото телефона.
- **Прайс-карточки + фото рядом**.
- Порядок блоков: Обложка → Обо мне → Партнёры → Статистика → Прайс → Долгосрочно → Контакты.

### 4.2 Что меняем под Мира
Адиль — предприниматель/футбол, у него холодный «корпоративный» navy. Мир — **художник и бьюти-блогер** (art | lifestyle | fashion | beauty), эстетика его ленты — тёмная, «киношная», с портретами крупным планом и чёрно-белыми рисунками. Поэтому:
- Палитра: не navy, а **чернила + серебро + один тёплый акцент** (жемчужно-розовый).
- Добавляем **арт-слой**: его линейные рисунки/скетчи (если есть в `assets/art/` или в стоп-кадрах арт-роликов) как полупрозрачные фоновые фрагменты в 1–2 секциях. Если рисунков нет — не имитировать, просто без них.
- Главный новый блок — **Кейсы с видео** (в PDF его нет, но это главная ценность сайта).

### 4.3 Токены (стартовые, можно тюнить по месту)

```css
:root {
  --bg: #07080b;          /* основной фон */
  --bg-2: #0e1117;        /* второй слой */
  --ink: #f3f4f7;         /* основной текст */
  --muted: #9aa3b2;       /* вторичный текст */
  --line: rgba(255,255,255,.14);
  --glass: rgba(255,255,255,.06);
  --accent: #f1b5c4;      /* жемчужно-розовый, ТОЛЬКО для акцентов: цифры, активный фильтр, бары графиков */
  --chrome: linear-gradient(180deg,#eef1f5 0%,#aab3c2 30%,#3a4453 62%,#07080b 100%);
  --radius-lg: 28px; --radius-md: 18px;
}
```
Сайт тёмный всегда (это стиль медиакита), отдельную светлую тему не делать. Контраст текста ≥ 4.5:1.

### 4.4 Шрифты (кириллица обязательна)
- Дисплейный (гигантские заголовки): **Oswald 700**, капс, `line-height: .85`, `letter-spacing: -.01em`, размер `clamp(64px, 13vw, 210px)`.
- Широкий (лейблы, подзаголовки, названия форматов): **Unbounded 500–700**, капс, трекинг `.02em`.
- Текст: **Manrope 400–600**, 16–18 px, `line-height: 1.5`.
- Если у какого-то шрифта нет кириллицы в `@fontsource` — заменить на ближайший с кириллицей и написать об этом в отчёте.

### 4.5 Сетка и адаптив
- Контейнер 1320 px, поля 24 px (мобайл 16 px). Брейкпоинты: 480 / 768 / 1024 / 1440.
- **Mobile-first**: 70% открытий будет с телефона (ссылку кидают в Telegram/WhatsApp). На 375 px ничего не должно вылезать по горизонтали.
- Каждая секция — минимум `100svh` на десктопе только там, где это оправдано (обложка). Остальные — по контенту.

### 4.6 Моушн
- Появление блоков: fade + translateY(24px), 600 ms, `cubic-bezier(.2,.7,.2,1)`, stagger 60 ms.
- Счётчики цифр — count-up при появлении (1.2 s).
- Хромированная лента — SVG-путь с металлическим градиентом, медленно «дышит» (10–14 s цикл).
- Телефоны на обложке — лёгкий параллакс/наклон от курсора на десктопе (≤ 6°).
- Всё отключается при `prefers-reduced-motion: reduce` (включая автоплей превью).

- Под ним строка ролей: «художник · бьюти-блогер · тату и перманент мастер» и «🇰🇿 Алматы · 🇺🇿 Ташкент».

### 5.2 Цифры (новый блок-полоса)
5 крупных счётчиков в ряд (на мобиле 2×3 или горизонтальный скролл):
`2 млн+ подписчиков` · `53,8 млн лайков в TikTok` · `68 млн+ просмотров Shorts` · `25 млн+ просмотров рекламы` · `24 бренда`.
Источник — `totals`. Под каждым — маленькая подпись с источником («TikTok @rinkiwi + @miirakhh»).

### 5.3 Обо мне (референс: ref-02 «Мои ценности»)
- По центру — **портрет Мира** со свечением сзади (как в референсе). Если удалось чисто вырезать фон (`rembg`) — вырезанный портрет; если нет или получилось грязно — фото в скруглённом прямоугольнике с виньеткой. **Портрет должен быть настоящим фото/кадром Мира, не генерацией.**
- Слева — 4 контент-направления из `contentPillars` (Арт · Бьюти и уход · Мода · Сюрпризы и лайфстайл): заголовок + 1 строка.
- Справа — факты со звёздочками (как в референсе): «22 года · Узбекистан», «Rinkiwi: рисунки с миллионами просмотров», «Тату и перманент мастер», пункты `whyMe`.
- Внизу — стеклянная плашка с `profile.bioLong` + кнопка **«▶ Смотреть знакомство»** → модалка с роликом `topContent[slug=intro]`.
- Блок «Не рекламирую…» (`restrictions`) — показывать только если `status !== 'missing'`.

### 5.4 Площадки
Карточки каналов из `channels` (кроме `minor: true` — Telegram-канал идёт мелкой ссылкой): иконка, @ник, подписчики, лайки/просмотры, роль канала («Арт-аккаунт», «Лайфстайл и интеграции»…), кнопка «Открыть». Обязательно пояснить, что у Мира **два TikTok**: арт @rinkiwi (1,2 млн) и лайфстайл @miirakhh (82 тыс., туда идут интеграции), и что Instagram раньше назывался @rinkiwii.

### 5.5 Партнёры (референс: ref-03)
- Гигантский заголовок **ПАРТНЁРЫ** (EN: PARTNERS).
- «Сцена»: тёмный зал, большой светящийся экран, на экране — сетка логотипов всех брендов из `cases` (включая Sodamoda). Сцену сделать CSS/SVG-средствами (градиент, свечение, отражение пола) — без стоковых фото людей.
- Логотип: `assets/logos/<slug>.svg|png` → если файла нет, **типографский вордмарк** (название бренда, Unbounded, белым, единый стиль для всех). Разнобой «пара логотипов + остальные текстом» не допускается: если логотипов меньше 70% — все делаем вордмарками.
- Samsung можно взять из Simple Icons. Остальные логотипы не качать с сомнительных сайтов.
- На мобиле — 2 ряда бегущей строки (marquee, пауза при `reduced-motion`).
- Подпись: «24 бренда · 62 ролика · 25 млн+ просмотров».

### 5.6 Кейсы (главный блок)
- Заголовок **КЕЙСЫ** + подзаголовок из `totals`.
- **Фильтр-чипсы** по `categories` (Все · Уход и косметика · Салоны, клиники, мастера · Мода и дом · Техника и сервисы · Путешествия · Цветы и подарки · Арт-коллаборации). Показывать только категории, в которых есть кейсы. Фильтрация на клиенте, без перезагрузки, URL-хэш `#cases/skincare`.
- Сортировка: сначала `featured: true`, внутри — по `totals.knownViews` (desc); кейсы без просмотров — в конце.
- **Карточка кейса** (`CaseCard.astro`), формат 9:16:
  - постер (см. §6.4), поверх — затемнение снизу;
  - бейдж с лучшей цифрой: «2,5 млн просмотров» (`totals.bestViews`); если просмотров нет — лайки/комментарии IG («2 171 лайк · 689 комментариев»); если нет ничего — без бейджа;
  - название бренда, категория, иконки платформ, «5 роликов» если кампания > 1 ролика;
  - превью `*-preview.mp4` играет беззвучно, когда карточка в зоне видимости (мобайл) / при наведении (десктоп); одновременно играют максимум 2; `preload="none"`.
- **Клик → модалка** (`VideoModal.astro`):
  - слева плеер (см. §6.5), справа: бренд + @ссылка на бренд, `summary`, таблица метрик основного ролика (просмотры, лайки, комменты, репосты, сохранения — только ненулевые), дата («февраль 2026»);
  - список **всех роликов кампании** (`sources`): платформа, дата, просмотры, кнопка «▶» (переключить плеер) и «↗» (открыть оригинал);
  - закрытие по Esc/клику по фону/крестику, фокус-ловушка, стрелки ←/→ — соседний кейс, свайп вниз на мобиле — закрыть.
- Featured-кейсы — крупные карточки (на десктопе 4 в ряд, на мобиле горизонтальная лента со snap), остальные — компактная сетка ниже.

### 5.7 Вирусный контент

## 6. Медиа

### 6.1 Скачивание
Запустить `python scripts/fetch_media.py` (подробности — в `CLAUDE.md`). Скрипт по каждому кейсу пробует источники в порядке TikTok → YouTube → Instagram (внутри — по просмотрам), берёт первый успешный ролик и делает `mp4` (≤720p), `-preview.mp4` (5 с, без звука), `webp`-постер и стоп-кадры. Итог — в `content/media-manifest.json`.

Известные ограничения:
- **Instagram** без входа часто не отдаёт видео. Для большинства IG-кейсов есть зеркала на YouTube/TikTok, скрипт их использует. Без зеркал: **Kima Beauty, GSJJ, intro** — для них нужны cookies (`--cookies-from-browser firefox` или `--cookies secrets/cookies.txt`) либо остаётся embed.
- **Два TikTok-ролика недоступны из Казахстана** (Birbir, один из Laseme) — статистика по ним `null`. Если не скачаются — у Laseme есть 5 YouTube-зеркал; у Birbir — только ссылка.

### 6.2 Фото Мира
Приоритет источников:
1. `assets/photos/*` — фото от заказчика (всегда главнее всего).
2. `media-src/gallery/*` — фото-посты Instagram (если `--gallery` с cookies сработал).
3. `media-src/stills/*` — стоп-кадры из топ-роликов и intro.

Claude Code **сам просматривает кандидатов** (Read умеет открывать картинки) и отбирает 5–8 лучших: чёткие, лицо в фокусе, без текста/субтитров поверх, без чужих людей крупным планом. Кадрирует, кладёт в `src/assets/photos/` с понятными именами (`hero.jpg`, `about.jpg`, `format-1.jpg`…). В отчёте перечислить, что откуда взято.

### 6.3 Аватар
`assets/photos/avatar.*` → иначе `media-src/channel/*avatar*` (аватар YouTube-канала, скрипт качает) → иначе кроп из стоп-кадра.

### 6.4 Постер карточки (цепочка fallback)
`manifest.items[slug].poster` → обложка любого YouTube-источника кейса из `manifest.thumbs` → `sources[].thumb` (удалённый i.ytimg.com) → **сгенерированная карточка**: градиент `--chrome`, вордмарк бренда, иконка платформы.

### 6.5 Плеер (цепочка fallback)
1. Локальный `mp4` из manifest → `<video controls playsinline preload="none" poster=…>`.
2. Иначе YouTube-источник → `iframe` `youtube-nocookie.com/embed/<id>?autoplay=1&playsinline=1` (грузить только по клику).
3. Иначе TikTok → `iframe` `https://www.tiktok.com/player/v1/<id>`.
4. Иначе Instagram → `iframe` `https://www.instagram.com/reel/<code>/embed`.
5. Иначе — постер + кнопка «Смотреть в <платформа> ↗».

Никакие iframe не грузятся до клика (facade-паттерн).
